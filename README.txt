FLASHBACK - Version 1 (free retro cameras)

Files: index.html, style.css, app.js  (keep them in the same folder)

Run it:
1. Unzip, then open the folder in VS Code.
2. Install the "Live Server" extension, right-click index.html, "Open with Live Server".
3. To try it on your phone, push the folder to GitHub and turn on GitHub Pages
   (Settings > Pages). The camera only works on https or localhost, so opening the
   file straight from your phone's Files app will NOT work.

Change the app name: edit <title> and the <h2> in index.html.
Tweak or add cameras: edit LOOKS at the top of app.js.
Change colors: edit the variables at the top of style.css.
